# Trade Operations manual probe matrix

Use with the [SalesBridge parity catalogue](0006-salesbridge-parity.md). Update **Status**, **Last run**, and **Evidence** after every probe. Record workspace build, member team, screen size, locale, test IDs and expected/actual values. Use a disposable tenant, synthetic order data, and a separate SQL Server 2017 container. Keep secrets, private company assets and production records out of captures.

Status is `PASS`, `PARTIAL`, `FAIL`, `FIXED` (manual rerun pending), `BLOCKED` (dependency named), or `UNTESTED`. Automated tests support a probe but cannot mark its manual result as passed. Test the visible path as well as the stored result.

## Acceptance priorities

| Area                     | Evidence required                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Representations          | Open every create and edit flow with the relevant Bolt role. Submit, reload, and confirm the stored value. Each field has one purpose and one owner. Remove repeated labels, descriptions and values where the record already supplies them.                                                                                                                                                   |
| Documents                | A layout record owns its structure and fields. Start with the configured published layout and allow an order-specific choice before approval. Generate previews and downloads on demand from captured data, with explicit stamp and signature choices. Keep company artwork and the salesperson’s approved signature on their owning records. Verify profile changes and unauthorized signing. |
| Ledgers and transactions | Confirm immutable agreement versions and retained financial evidence. Race simultaneous edits, duplicate deliveries and dropped acknowledgements. Corrections preserve the earlier evidence and update the current view once.                                                                                                                                                                  |
| Reports                  | Tie report definitions, cutoffs, filters, totals, permissions and exports back to SalesBridge. Reconcile against the same source facts and currencies.                                                                                                                                                                                                                                         |
| Direct Kingdee sync      | Complete normal work against the local database with the link disabled. Verify outbound and inbound replay, identity, eventual reconciliation and ledger isolation. Measure peak bytes, round-trip latency, backlog and recovery on the Alibaba route.                                                                                                                                         |
| Flexible orders          | Quote, sales confirmation and purchase commitments use the shared order flow. Terms can change under the same order identity. Exactly one accepted agreement is current. Existing invoices and deliveries retain their version links.                                                                                                                                                          |
| Access                   | Run each workflow under existing Bolt roles. Verify reads, writes, approval, file bytes and signature use for permitted and denied users.                                                                                                                                                                                                                                                      |
| Pricing and commission   | Probe quantity tiers, effective dates, authorized quote limits, price guidance and sealed commission calculations.                                                                                                                                                                                                                                                                             |
| Stock by lot             | Probe FIFO over lots with different costs. Reconcile physical and available quantities, actual lot consumption, and the resulting margin. | Sales performance        | Reconcile per-person volume, revenue, margin and commission against the source definitions.
