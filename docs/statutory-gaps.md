# Statutory review history

Historical review register, 18–19 September 2026. The tables preserve the issue numbers,
instruments and implementation notes from those reviews. They are not a current legal
certification. The [compliance matrix](compliance-matrix.md) records current blockers and
obligations outside calculation; the [implementation register](gap-tracker.md) records related
model coverage.

`Implemented` records a reported code or configuration change, not independent legal approval.
`MONEY` identifies calculation impact; `BUILD` identifies missing implementation; `SEED` identifies
configuration work; `DECLARED` identifies required employee facts; `CALENDAR` identifies a future
version; `OUTSIDE`, `RECORDS` and `SOURCE` identify procedural, evidence or source issues.
Employer practice cannot replace a statutory requirement.
