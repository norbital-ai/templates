# Service Scheduling — Source Reference

Authoritative inventory of workspace configuration, models, apps, representations, access control,
automations, syncs, integrations, shared library modules, localization catalogs, and tests in
`templates/scheduling`.

## Workspace Manifest (`src/+workspace.ts`)

- **Defaults:** `tz: 'UTC'`, `locale: 'en'`, `languages: ['en', 'zh']`, `currency: 'USD'`,
  `theme: { palette: 'crisp', accent: 'blue', radius: 'default' }`.
- **Apps:** `['scheduling', 'configuration', 'provider', 'portal']`.
- **Self-signup:** `via: ['phone']`, `policies: ['customer']`, `party: { model: 'customers', match: { phone: 'phone' } }`, `challenge: true`.
- **Rate limits:**
  - `operations`: `read: 600/min`, `act: 600/min`, `agent: 100/h`
  - `provider`: `read: 600/min`, `act: 120/min`, `agent: 50/h`
  - `provider_shift`: `read: 600/min`, `act: 120/min`
  - `dispatch_automation`: `read: 600/min`, `act: 600/min`
  - `customer`: `read: 300/min`, `act: 30/h`
  - `portal_visitor`: `read: 120/min`

## Integrations

- **`google_routes` (`src/integration/google_routes/+integration.ts`):** Custom HTTP integration (`https://routes.googleapis.com/`, `X-Goog-Api-Key` header from sealed `api_key` credential) queried via `POST distanceMatrix/v2:computeRouteMatrix`.
- **Built-in `whatsapp` and `email`:** Shared workspace connections (`owner: null`, declared in `+workspace.ts`) configured through **Settings → Integrations → Connections**.
- **Built-in `ctx.geo.search`:** Geocodes customer addresses during `prepare_availability` and `portal_intake`.
