# 人力资源管理

![人力资源管理应用界面](docs/screenshots/application.webp)

人力资源管理（HRMS）是一套面向多法人实体、多发薪周期与多国合规环境的一体化人事、考勤与薪酬工作区。它在一个统一平台内覆盖员工入职后的全周期业务——从人事档案、雇佣合同、班次排班与人脸考勤，到休假、报销、员工借款、职场事件、薪酬核算、工资清单、银行代发文件与法定合规义务管理——并内置九个亚太司法辖区的法定基线规则（中国大陆、印度尼西亚、日本、马来西亚、菲律宾、新加坡、泰国、中国台湾与越南）。

借助这一工作区，人力资源与财务团队不再需要维护分散在各国的薪酬表格、手工休假台账、邮件审批链与易错的追溯补差计算。各国法定规则、公司计薪办法与员工合同条款均以“按生效日期管理的数据”沉淀，而非写死在特定国家逻辑中；已支付的薪酬批次永久锁定以保障审计完整性，任何针对历史记录的源头更正都会自动将逐项差额结转至下一次核算。

## 预期业务价值

- **统一多国多实体人事与薪酬运作：** 将法人实体设置、员工档案、排班考勤、休假、报销、借款及薪酬核算整合至同一工作区，内置九个亚太辖区规则，替代分散的各国表格与割裂工具。
- **可审计的薪酬准确性与无痛追溯补差：** 已支付批次与工资单永久不可篡改；当早期考勤、休假、报销或合同条款在源头更正时，系统自动重算同一税务年度内受影响的周期，并仅将逐项净差额结转至后续核算，杜绝手工改表与对账断层。
- **防篡改的额度台账与费用管控：** 假期余额、年度报销上限、结转规则及离职年假折算或追回均由只增不减的变动台账推导，有效避免余额漂移、重复请假或未经审批的发放。
- **清晰的权责隔离与薪酬保密边界：** 基于角色的权限模型明确区分员工自助、车间考勤终端、直线主管审批、人事薪酬专员与高管治理职责——杜绝本人自批，并将敏感薪资信息与公共考勤终端彻底隔离。
- **主动式法规变化追踪：** 每周自动巡检官方政府、税务与社保网站，附带官方出处引文提出变更发现，并预先草拟尚未生效的按日期更新草案，供人事团队审核确认后再启用。

| **考勤终端（Attendance Kiosk）**                                             | 考勤打卡终端               | 面向办公或厂区共享考勤设备的隔离账号；仅可识别所属法人实体内已审核通过的在职员工并记录上下班打卡，完全无法访问薪资、工资单、休假、报销或员工隐私档案。                                 |

**治理与保密防线**

- **严禁本人自批：** 任何审批人均无法批准本人提交的休假或报销申请。
- **员工申请审批暂挂机制：** 员工提交的休假与报销申请需经两级审批（直线主管 -> 人事）方可生效，除非由人事经理或高级管理层越级审批；审批完成前不入台账，并阻止包含该员工的薪酬批次生成，直至审批结案。由人事直接录入的记录立即生效。
- **发薪冻结与永久锁定：** 存在未支付薪酬批次时，系统锁定涉及员工的相关记录修改，直至该批次标记为已支付或被删除；一旦标记为已支付，批次与工资单永久锁定，任何报表导出均直接读取已存结果而不重新计算。
- **法规变更人工核验闸门：** 自动法规研究仅生成“待审核发现”与休眠状态的更新草案，必须由人事成员核对官方出处并正式确认后，变更才会生效。

## 应用与核心功能

### 人事运营套件

| 应用 / 模块                  | 核心功能                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **工作台（Dashboard）**      | 汇总四类实时待办队列与计数：等待当前审核人处理的跨实体审批、尚未支付的薪酬批次、待办合规义务，以及待人事审核的法规变更发现。                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **法人实体（Entities）**     | 多公司主数据管理，支持多实体批量导入《数据采集工作簿（Data Request）》与节假日表格。每个实体下设五个标签页：**常规设置**（公司基本信息、银行账户、迟到提醒阈值与通知角色、按日期生效的公司计薪办法、离职终薪借款扣款保底比例、按日期生效的雇主法定参数）、**发薪组**（支持按月、半月、旬、多月、按周、双周及按日周期，含考勤截止日与工作日顺延规则）、**班次**、**轮班模式**（按周或循环排班）以及可逐条发布的**节假日**（支持调休替代节假日与按员工班次调整的节假日）。                                                                                  |
| **人员管理（People）**       | 提供员工名录（默认筛选当日在职人员、支持批量导入与人脸采集状态查看）及**人员概览**（当前在职人数及近 12 个月入职与离职率趋势图）。每位员工档案包含六个子视图：**个人档案**（联系方式、基础信息、人脸采集审批与状态管理、按日期生效的法定参数、家属信息）、**雇佣合同**（按时间倒序展示历次雇佣期，支持入职/复职、同实体或跨实体调动、离职办理以及按日期生效的薪资与津贴条款）、**文档资料**、**借款记录**、**职场事件**与**额度余额**（剩余额度总览与完整变动台账，人事控制角色可录入台账手工调整）。                                                     |
| **日常事件（Events）**       | 覆盖七类按日期记录的员工活动台账，均支持 Excel 工作簿批量导入：**工作排班**（按公司展示月度排班与考勤看板，自动提示法定工时与加班上限预警，支持排班导入/导出与加班报表导出）、**休假**（支持上下午半天日历点选与假期折现）、**报销**（附凭证上传与年度上限校验）、**临时项目**（奖金、遣散费、法定退补及一次性奖惩）、**借款**（员工预支/借款及自动月度还款计划与回收追踪）、**职场事件**（违纪、事故或人事案件的严重程度、日期与证据附件管理）以及**工作事件**（面向全公司或特定员工的极端天气、公共卫生或停工等按日期生效条件，供休假与补贴规则读取）。 |
| **薪酬核算（Payroll Runs）** | 按法人实体、发薪组与期间创建常规（周期内）或周期外薪酬批次；逐人核对工资单明细与往期追溯调整项；支持标记为已支付（永久锁定）或删除未支付批次；一键导出可审计的**工资清单（Salary Listing）**多工作表 Excel（含已保存汇总与逐行明细）、**加班报表（Overtime Report）**（含周期汇总与按日明细）以及银行代发文件（**OCBC FAST** 与 **Metrobank**）。                                                                                                                                                                                                         |
| **合规义务（Obligations）**  | 统一追踪各项法定申报与合规任务——包括税务与社保缴纳、工作准证或退休核查、员工离职手续，以及未收回借款或离职多发款项的追偿跟进——支持“待办 / 已完成 / 已豁免”流转与合规凭证上传。                                                                                                                                                                                                                                                                                                                                                                            |
| **法规设置（Settings）**     | 按日期查看与编辑九个内置司法辖区的完整法定规则，涵盖七个标签页（**常规**、**查表参数**、**计算总览**、**项目目录**、**登记规则**、**登记行为**与**变更日志**）。保存修改时可选择“向来如此”追溯修正或“自指定日期生效”前瞻更新，并可在变更日志中手动触发法规巡检。                                                                                                                                                                                                                                                                                          |

### 员工自助与考勤采集

| 应用 / 模块                               | 核心功能                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **员工自助服务（Employee Self-Service）** | 专属员工门户，包含六个标签页——**首页**（个人工作日程，支持多段有效雇佣关系切换）、**休假**（申请时实时显示剩余假期额度）、**报销**（上传收据凭证提交申请）、**借款**（只读查看还款进度）、**文档**（上传个人材料）与**我的工资单**（只读查阅历史工资单）——并内置五姿态引导式自助人脸采集，提交后自动流转至人事审核。 |
| **考勤打卡终端（Attendance Kiosk）**      | 绑定单个法人实体的全屏共享打卡界面，集成端侧人脸识别与活体防伪校验、1 秒稳定确认、60 秒防重复打卡冷却、中英双语语音播报，以及按姓名手动打卡兜底方案。                                                                                                                                                                |

## 自动化与外部连接

- **假期与报销台账自动同步：** 每年 1 月 1 日自动运行，并在即将到来的入职周年、额度窗口切换以及合同条款、法规变更或薪酬已支付时自动触发——计算假期应得额度、报销年度上限、旧周期结转与历史余额归档；若同步异常需人工处理，系统自动生成一条人事合规任务。
- **法定合规义务自动派生：** 当员工休假、报销或档案记录获批后，自动按辖区法规评估是否需要履行法定申报或跟进手续，并去重创建合规义务任务，避免漏办错办。
- **实时迟到提醒：** 监控当日实时打卡记录与排班开始时间，一旦员工首次打卡超过实体设定的宽限分钟数，每日仅向指定角色发送一次迟到通知。
- **每周法规巡检与草案起草：** 每周六自动运行（也可在法规设置页手动触发），针对当前在用的每个司法辖区巡检官方政府、税务与社保网站，对发现内容去重并留存官方出处，同时起草休眠状态的按日期更新草案，等待人事审核确认。
- **受邀员工入职自动关联：** 当受邀成员接受工作区邀请加入时，自动将其账号与对应员工档案关联（或自动建档），让新员工即刻可用员工自助服务。
- **工作簿、银行代发文件与官方数据源：** 支持覆盖初始化数据采集、节假日、排班、日常事件、工资清单与加班报表的结构化 Excel 导入导出；内置 **OCBC FAST** 与 **Metrobank** 定长银行代发文件导出；法规研究期间自动查阅官方公开政府及监管网站。

## 范围与职责边界

- **开箱即用范围：** 多法人实体人事档案管理、班次排班与人脸考勤采集、休假/报销/借款/职场事件审批与台账、内置九个亚太辖区的按日期计薪与法定核算引擎、跨周期追溯补差、工资单、工资清单、加班报表、OCBC FAST 与 Metrobank 银行代发文件生成，以及合规义务任务追踪。
- **政府申报、资金解缴与法律税务咨询：** 系统负责法定税费与社保核算、义务提醒以及法规变动巡检，但不直接向政府门户电子报税、不代理缴款，亦不替代专业法律或税务顾问意见。人事团队须对拟采纳的法规变更进行人工核验并完成官方申报。
- **银行直连划款与资金司库：** 系统生成符合银行规范的代发文件供财务上传，但不直接发起银行实时转账、不执行司库资金审批，也不进行银行对账。
- **企业总账与 ERP 财务核算：** 系统为财务团队提供可审计的工资清单与雇主成本明细，但不替代企业财务总账系统、会计凭证过账或 ERP 核算模块。
- **招聘、绩效与培训管理：** 本工作区聚焦入职后的人事运营、考勤与薪酬核心链路；招聘流程管理、绩效考核与培训学习体系不在本工作区覆盖范围内。
- **线下考勤硬件与网络环境：** 考勤终端运行于配备摄像头的标准浏览器中；平板或一体机采购、现场安装、采光布置及本地网络运维由使用方自行负责。
