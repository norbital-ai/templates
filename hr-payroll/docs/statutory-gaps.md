# Statutory gaps — the open register

The obligations the engine does not yet compute exactly as the instrument states, enumerated on
2026-09-18 from every record we keep and re-cut the same evening after the fourth batch landed
(rows marked **landed (4)** below stay for one release as the audit trail, then move to the
tracker's ledger): `gap-tracker.md` (rows), the lineage READMEs' NOT APPLIED
lists (`seed_bank/norbital_hr/jurisdiction/<J>/README.md`) and the `authority` notes on the bank's
rows. Rows here cite their tracker number where one exists; the README-only items were given
tracker rows 116–130 on the same day so nothing lives only in prose. Close a row here by landing
it and moving the line to the tracker's §4 ledger.

Classes:

- **MONEY** — a figure on a built run is wrong today.
- **DECISION** — the seed reproduces the employer's own listing where the law says otherwise; the
  owner picks.
- **SEED** — the grammar carries it; one row edit closes it.
- **BUILD** — a context member or engine primitive is missing.
- **DECLARED** — a profile field holds it; not verifiable from inside the tenant.
- **CALENDAR** — the law is not in force or the figure is not published.
- **OUTSIDE / RECORDS / SOURCE** — outside payroll, missing data, or two sources disagree.
