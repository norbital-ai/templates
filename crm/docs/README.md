[Activity timeline design](./design/activity-timeline.md) describes conversation grouping, source identity, meeting
recording and activity presentation.

Personal connections and the workspace's channels (and Apollo) are paired in **Configuration → Connections** with the
native provider setup. Gmail and Calendar require a configured host OAuth client. Sales members read the template
catalogue; teams, policies, approval flows and template-author authority remain source declarations.
